# دليل تطوير تطبيق مواد البناء الجوال

## البدء السريع

### 1. إعداد البيئة
```bash
# تثبيت Node.js (إصدار 18 أو أحدث)
# تثبيت Expo CLI
npm install -g @expo/cli

# استنساخ المشروع
cd BuildingMaterialsApp

# تثبيت التبعيات
npm install
```

### 2. تشغيل التطبيق
```bash
# تشغيل خادم التطوير
npm start

# خيارات التشغيل:
# - اضغط 'a' لفتح Android emulator
# - اضغط 'i' لفتح iOS simulator  
# - اضغط 'w' لفتح في المتصفح
# - امسح QR code بتطبيق Expo Go
```

## إضافة مكون جديد

### 1. إنشاء المكون
```javascript
// src/components/CustomButton.js
import React from 'react';
import { TouchableOpacity, Text, StyleSheet } from 'react-native';
import { Colors, Spacing, FontSizes, BorderRadius } from '../constants/Colors';

const CustomButton = ({ title, onPress, style, disabled = false }) => {
  return (
    <TouchableOpacity
      style={[styles.button, disabled && styles.disabled, style]}
      onPress={onPress}
      disabled={disabled}
    >
      <Text style={[styles.text, disabled && styles.disabledText]}>
        {title}
      </Text>
    </TouchableOpacity>
  );
};

const styles = StyleSheet.create({
  button: {
    backgroundColor: Colors.primary,
    borderRadius: BorderRadius.md,
    paddingVertical: Spacing.md,
    paddingHorizontal: Spacing.lg,
    alignItems: 'center',
  },
  disabled: {
    backgroundColor: Colors.gray[400],
  },
  text: {
    fontSize: FontSizes.md,
    fontWeight: '600',
    color: Colors.white,
  },
  disabledText: {
    color: Colors.gray[600],
  },
});

export default CustomButton;
```

## معالجة الأخطاء

### 1. معالجة أخطاء API
```javascript
const handleApiCall = async () => {
  try {
    const response = await apiService.getData();
    // معالجة النجاح
  } catch (error) {
    if (error.response) {
      // خطأ من الخادم
      const status = error.response.status;
      const message = error.response.data?.message || 'خطأ في الخادم';
      Alert.alert('خطأ', message);
    } else if (error.request) {
      // مشكلة في الشبكة
      Alert.alert('خطأ', 'تحقق من اتصال الإنترنت');
    } else {
      // خطأ آخر
      Alert.alert('خطأ', 'حدث خطأ غير متوقع');
    }
  }
};
```

## البناء والنشر

### 1. بناء للإنتاج
```bash
# بناء APK للأندرويد
expo build:android

# بناء IPA للآيفون
expo build:ios

# بناء باستخدام EAS (الطريقة الجديدة)
npx eas build --platform android
npx eas build --platform ios
```

### 2. النشر
```bash
# نشر على Expo
expo publish

# نشر باستخدام EAS
npx eas submit --platform android
npx eas submit --platform ios
```

## نصائح التطوير

### 1. تنظيم الكود
- استخدم أسماء واضحة للمتغيرات
- اكتب تعليقات للكود المعقد
- قسم الكود إلى مكونات صغيرة
- استخدم TypeScript للمشاريع الكبيرة

### 2. الأداء
- تجنب re-renders غير الضرورية
- استخدم lazy loading للصور
- قلل من استخدام inline styles
- استخدم FlatList للقوائم الطويلة

### 3. UX/UI
- اختبر على أحجام شاشات مختلفة
- استخدم loading indicators
- أضف feedback للمستخدم
- اتبع إرشادات Material Design/Human Interface

### 4. الأمان
- لا تخزن معلومات حساسة في الكود
- استخدم HTTPS للـ APIs
- تحقق من صحة البيانات
- استخدم authentication مناسب
