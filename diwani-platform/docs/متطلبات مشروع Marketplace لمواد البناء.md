# متطلبات مشروع Marketplace لمواد البناء

## نظرة عامة
منصة إلكترونية تجمع موردي مواد البناء والعملاء في السوق السعودية، تتيح للموردين عرض منتجاتهم وللعملاء تصفحها وإرسال طلبات الشراء.

## الجمهور المستهدف
- **السوق**: المملكة العربية السعودية
- **الموردين**: شركات ومؤسسات توريد مواد البناء
- **العملاء**: أفراد وشركات تحتاج مواد البناء

## أنواع المستخدمين

### 1. المدير (Admin)
- إدارة الموردين والعملاء
- مراجعة وموافقة طلبات التسجيل
- إدارة الفئات والمنتجات
- مراقبة النشاط والإحصائيات

### 2. المورد (Supplier)
- تسجيل حساب جديد
- إدارة الملف الشخصي والشركة
- إضافة وتعديل المنتجات
- تصنيف المنتجات حسب الفئات
- استقبال وإدارة الطلبات
- تحديث حالة الطلبات

### 3. العميل (Customer)
- تسجيل حساب جديد
- تصفح المنتجات والموردين
- البحث والفلترة
- إضافة المنتجات للسلة
- إرسال طلبات للموردين
- متابعة حالة الطلبات

## الميزات الأساسية

### 1. نظام التسجيل والمصادقة
- تسجيل دخول/خروج
- إنشاء حسابات جديدة
- استعادة كلمة المرور
- التحقق من البريد الإلكتروني

### 2. إدارة الملفات الشخصية
- معلومات الشركة/الفرد
- بيانات الاتصال
- الموقع الجغرافي
- رخص العمل والشهادات

### 3. إدارة المنتجات
- إضافة منتجات جديدة
- تصنيف المنتجات
- رفع صور المنتجات
- تحديد الأسعار والمواصفات
- إدارة المخزون

### 4. نظام البحث والفلترة
- البحث بالكلمات المفتاحية
- فلترة حسب الفئة
- فلترة حسب السعر
- فلترة حسب الموقع
- ترتيب النتائج

### 5. نظام الطلبات
- إضافة للسلة
- إرسال طلبات للموردين
- تتبع حالة الطلبات
- تاريخ الطلبات

### 6. نظام التقييم والمراجعات
- تقييم الموردين
- مراجعات المنتجات
- نظام النجوم

## المتطلبات التقنية

### Frontend
- React.js
- Material-UI أو Bootstrap
- Responsive Design
- PWA Support

### Backend
- Flask (Python)
- RESTful API
- JWT Authentication
- File Upload Support

### Database
- SQLite (للتطوير)
- PostgreSQL (للإنتاج)

### الاستضافة
- Frontend: Vercel/Netlify
- Backend: Heroku/DigitalOcean
