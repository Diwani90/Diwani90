# دليل المستخدم - منصة مواد البناء

## نظرة عامة

منصة مواد البناء هي marketplace متكامل يستهدف السوق السعودية، يتيح للموردين عرض منتجاتهم وللعملاء (أفراد وشركات) تصفحها وإرسال طلبات شراء مباشرة للموردين.

## رابط المنصة

🌐 **الرابط المباشر:** https://e5h6i7c0jpq1.manus.space

## الميزات الرئيسية

### للعملاء:
- **تصفح المنتجات:** عرض شامل لجميع مواد البناء مقسمة حسب الفئات
- **البحث المتقدم:** إمكانية البحث بالاسم، الفئة، السعر، والمدينة
- **معلومات الموردين:** عرض تفاصيل كاملة عن الموردين وتقييماتهم
- **إرسال الطلبات:** إمكانية إرسال طلبات شراء مباشرة للموردين
- **مقارنة الأسعار:** مقارنة أسعار نفس المنتج من موردين مختلفين

### للموردين:
- **إدارة المنتجات:** إضافة وتعديل وحذف المنتجات
- **إدارة الطلبات:** استقبال ومتابعة طلبات العملاء
- **إحصائيات المبيعات:** تقارير شاملة عن الأداء والمبيعات
- **إدارة الملف الشخصي:** تحديث معلومات الشركة والتخصصات

## الفئات المتاحة

1. **خرسانة وأسمنت** - جميع أنواع الخرسانة والأسمنت ومواد البناء الأساسية
2. **حديد وصلب** - حديد التسليح والصلب بجميع الأنواع والمقاسات
3. **طوب وبلوك** - الطوب الأحمر والبلوك الخرساني وطوب العزل
4. **عزل** - مواد العزل الحراري والمائي والصوتي
5. **أبواب ونوافذ** - الأبواب والنوافذ الخشبية والألمنيوم والحديدية
6. **سيراميك وبلاط** - السيراميك والبورسلين والرخام والجرانيت
7. **سباكة** - أنابيب وتجهيزات السباكة والصرف الصحي
8. **كهرباء** - الكابلات والمفاتيح واللوحات الكهربائية

## كيفية استخدام المنصة

### للعملاء:

#### 1. تصفح المنتجات
- ادخل إلى الصفحة الرئيسية
- اختر الفئة المطلوبة من القائمة الرئيسية
- تصفح المنتجات المتاحة في كل فئة

#### 2. البحث عن منتج معين
- استخدم شريط البحث في أعلى الصفحة
- يمكنك البحث بـ:
  - اسم المنتج
  - اسم المورد
  - المدينة
  - نطاق سعري محدد

#### 3. عرض تفاصيل المنتج
- اضغط على أي منتج لعرض التفاصيل الكاملة
- ستجد معلومات عن:
  - الوصف التفصيلي
  - المواصفات التقنية
  - السعر والوحدة
  - الحد الأدنى للطلب
  - معلومات المورد

#### 4. إرسال طلب شراء
- في صفحة المنتج، اضغط على "إرسال طلب"
- املأ النموذج بالمعلومات المطلوبة:
  - الاسم الكامل
  - البريد الإلكتروني
  - رقم الهاتف
  - العنوان الكامل
  - نوع العميل (فرد/شركة)
  - الكمية المطلوبة
  - ملاحظات إضافية

### للموردين:

#### 1. التسجيل كمورد
- تواصل مع إدارة المنصة لإنشاء حساب مورد
- قدم المستندات المطلوبة للتحقق
- انتظر الموافقة على الحساب

#### 2. إضافة المنتجات
- ادخل إلى لوحة التحكم
- اضغط على "إضافة منتج جديد"
- املأ جميع المعلومات المطلوبة:
  - اسم المنتج
  - الوصف التفصيلي
  - السعر والوحدة
  - الفئة
  - المواصفات التقنية
  - صور المنتج
  - الكمية المتوفرة

#### 3. إدارة الطلبات
- راجع الطلبات الواردة في قسم "الطلبات"
- قم بتحديث حالة كل طلب:
  - معلق (Pending)
  - مؤكد (Confirmed)
  - تم الشحن (Shipped)
  - تم التسليم (Delivered)
  - ملغي (Cancelled)

## API Documentation

المنصة توفر API متكامل للمطورين:

### Base URL
```
https://e5h6i7c0jpq1.manus.space/api
```

### Endpoints الرئيسية:

#### الفئات
- `GET /categories` - جميع الفئات
- `GET /categories/main` - الفئات الرئيسية فقط
- `GET /categories/{id}` - فئة محددة

#### الموردين
- `GET /suppliers` - جميع الموردين
- `GET /suppliers/featured` - الموردين المميزين
- `GET /suppliers/{id}` - مورد محدد

#### المنتجات
- `GET /products` - جميع المنتجات مع إمكانية التصفية
- `GET /products/featured` - المنتجات المميزة
- `GET /products/search` - البحث المتقدم
- `GET /products/{id}` - منتج محدد

#### الطلبات
- `POST /orders` - إنشاء طلب جديد
- `GET /orders` - جميع الطلبات
- `GET /orders/{id}` - طلب محدد
- `PUT /orders/{id}/status` - تحديث حالة الطلب
